运行方式

进入 demo/ 目录，启动任意静态服务器即可：

cd docs/doc-01-数据/demo python -m http.server 8080 # 浏览器打开 http://localhost:8080

或用 VSCode Live Server 插件一键启动，无需安装任何依赖。
